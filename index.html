Deep Dive: Real-Time Audio with FPGAs

Developed a real-time, multi-band audio equalizer on a Xilinx FPGA. This project involved designing and implementing digital filters using VHDL, demonstrating a strong understanding of digital signal processing and hardware description languages.

Key Features

  • Five-band adjustable graphic equalizer.
  • High-throughput, low-latency audio processing.
  • Implemented using pipelined FIR filter architecture.
  • Designed and simulated in Vivado Design Suite.

Technical Stack

VHDL Xilinx FPGA Vivado Digital Signal Processing

The Future of Farming: An IoT Approach

Tech for Good: A Haptic Navigator

Designed and built a wearable device that uses ultrasonic sensors to detect obstacles and provides haptic feedback to the user through vibration motors, enabling safer and more independent navigation.

Key Features

  • Multi-sensor array for 180-degree obstacle detection.
  • Directional haptic feedback to indicate obstacle location.
  • Low-power design for extended battery life.
  • Compact and ergonomic wearable form factor.

Technical Stack

ESP32 C++ (Arduino) Ultrasonic Sensors 3D Printing
